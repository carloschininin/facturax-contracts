# Ejemplos JSON

Estos archivos sirven como referencia inicial para integradores del package `carloschininin/facturax-contracts`.

## Archivos disponibles

- `v1/comprobante-factura.json`
- `v1/nota-credito.json`
- `v1/resumen-diario.json`
- `v1/comunicacion-baja.json`
- `v1/guia-remision.json`
- `v1/percepcion.json`
- `v1/retencion.json`
- `v1/reversion.json`

## Notas

- Los ejemplos reflejan la **estructura esperada del contrato**.
- El emisor autenticado no viaja en el payload.
- Los DTOs públicos están desacoplados de Greenter, aunque luego puedan mapearse internamente a sus modelos.
